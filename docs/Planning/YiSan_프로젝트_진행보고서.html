과정명 프로그래밍 기반 얼라인 프로젝트
트랙 Unreal Engine
프로젝트 YiSan - 정조대왕 능행차 기반 역사 체험 게임

[프로젝트 개요]

항목 내용
제목 YiSan: C++ UE5 기반 차세대 역사 체험형 게임
한 줄 설명 언리얼 엔진5의 최신 기술을 활용하여 정조대왕 능행차를 배경으로 한 고밀도 NPC 상호작용 및 실시간 이벤트를 구현한 기술 중심 프로젝트
기획 의도 World Partition, MassAI 등 최신 기술을 통해 기존 게임에서 불가능했던 대규모 NPC와의 상호작용을 구현하고, C++ 기반의 커스텀 라이브러리를 설계하여 확장성 높은 게임플레이 아키텍처를 구축하고자 함.
참여 인원 3명 (리드 프로그래머 1, 월드/콘텐츠 1, AI/시스템 1)
본인 역할 리드 프로그래머: C++ 핵심 아키텍처 설계, UI, AI(GPT 연동), 음성(TTS/STT), 네트워크 등 핵심 시스템 개발 및 프로젝트 관리(CI/CD, 문서화, 코드 리뷰) 총괄
진행 기간 2025년 9월 30일 ~ 2025년 11월 4일 (약 5주)
프로젝트 링크 https://github.com/doppleddiggong/YiSan

[기술 스택]

구분 기술 선택 이유
엔진/언어 Unreal Engine 5.6, C++20 고품질 그래픽, World Partition, Nanite 등 최신 기술 활용 및 C++ 기반의 성능 최적화
AI MassAI, GPT 수백 명의 NPC를 효율적으로 제어하는 MassAI와, GPT 연동을 통한 지능적인 음성 상호작용 구현
라이브러리 LatteLibrary, CoffeeLibrary 게임플레이 로직과 공용 유틸리티를 모듈화하여 코드 재사용성 및 확장성 확보
네트워크 Tailscale 복잡한 방화벽 설정 없이 개발자 간 P2P 연결을 용이하게 하여 원격 멀티플레이 테스트 환경 구축
개발/관리 Git, GitHub, PowerShell, Doxygen 버전 관리, CI/CD(ai-review), 빌드/테스트 자동화, 코드 문서 자동 생성을 통한 체계적인 개발 프로세스 구축

[프로젝트 진행 단계]

  1. 프로토타입 (2025.09.30 ~ 2025.10.20)

    • C++ 기반 핵심 아키텍처 설계 (LatteLibrary, CoffeeLibrary 모듈 구축)
    • 핵심 기능 기술 검증(PoC): UI(팝업), AI(GPT 연동), 음성(TTS/STT) 시스템 구현
    • World Partition 기반의 기본 레벨 및 MassAI 시스템 초기 통합

  2. 알파 (2025.10.21 ~ 2025.10.31)

    • 프로토타입 기능 고도화 및 시스템 안정화
    • 멀티플레이어 기능 구현 시작: Seamless Travel 및 PlayerState 연동 시도
    • Tailscale을 이용한 원격 멀티플레이 테스트 환경 구축 및 문제 식별

  3. 베타 & 폴리싱 (2025.11.01 ~ 2025.11.04)

    • 기능 완성 및 최종 빌드, 발표 준비
    • World Partition 환경에서의 로딩 위젯 표시 문제, Standalone 모드에서의 플레이어 인덱스 동기화 문제 등 네트워크 관련 이슈 집중 해결
    • 최종 시연 과정에서 발생한 하드웨어 및 네트워크 이슈로 인한 문제 해결 및 회고 진행

[프로젝트 세부 과정]

  1. C++ 기반 모듈형 아키텍처 구축

    • 구현: LatteLibrary(캐릭터/전투/네트워크)와 CoffeeLibrary(공용 유틸리티)로 기능을 분리하여 설계.
    • 성과: 각 기능의 의존성을 낮추고 독립적인 개발 및 테스트가 가능한 구조를 마련하여 유지보수성과 확장성을 크게 향상시킴. (CTO 평가 인용)

  2. AI 기반 상호작용 시스템

    • 구현: MassAI를 활용해 대규모 군중 NPC를 구현하고, GPT를 연동한 음성 인식(STT) 및 응답(TTS) 시스템을 구축하여 NPC와 대화하는 기능 구현.
    • 성과: 단순한 패턴을 넘어 사용자와 실시간으로 상호작용하는 역동적인 월드를 구현할 기술적 기반을 마련함.

  3. 네트워크 및 멀티플레이어 시스템

    • 구현: Seamless Travel을 이용한 월드 이동 및 Standalone 빌드에서의 멀티플레이 테스트 진행.
    • 문제 해결: PIE와 달리 Standalone 모드에서 PlayerState의 PlayerIndex가 보장되지 않는 문제를 발견. 이는 Seamless Travel 시 서버가 클라이언트의 상태를 완전히 신뢰하지 않고 재설정하기 때문. 이 문제를 해결하기 위해 플레이어 입장 시 인덱스를 재검증하고 할당하는 로직의 필요성을 확인함.
    • 성과: 복잡한 World Partition 환경에서의 멀티플레이 동기화 문제에 대한 깊은 기술적 이해를 얻고, Tailscale과 같은 VPN을 활용한 실질적인 원격 테스트 경험을 쌓음.

  4. 개발 프로세스 자동화

    • 구현: Doxygen을 통한 코드 문서 자동 생성, PowerShell을 이용한 DevLog 자동 작성 및 테스트 스크립트, GitHub Actions를 이용한 AI 코드 리뷰(ai-review.yml) 도입.
    • 성과: 개발 생산성을 높이고, 코드 품질을 일관되게 유지하며, 체계적인 프로젝트 관리 기반을 구축함.

[프로젝트 결과]

  • 기술적 성과

    • 아키텍처: C++ 기반의 견고한 모듈형 아키텍처를 구축하여 확장성과 재사용성 확보.
    • 최신 기술 도입: MassAI, World Partition, GPT 등 최신 기술을 성공적으로 프로젝트에 통합.
    • 문제 해결 능력: Standalone 환경의 Seamless Travel과 같이 문서화가 부족한 영역의 문제를 직접 분석하고 해결 방안을 모색하는 깊이 있는 기술 탐구 능력 입증.

  • 구현 기능

    • 핵심 시스템: 모듈화된 C++ 라이브러리, MassAI 기반 NPC, 음성 인식/응답 상호작용.
    • 월드: World Partition 기반의 대규모 월드 및 시네마틱 연출.
    • 네트워크: Tailscale을 이용한 원격 멀티플레이 테스트 환경.

  • 정량적 성과

    • 커밋 수: 783+
    • 개발 기간: 약 5주
    • 문서화: Doxygen 및 DevLog를 통한 체계적인 개발 기록 관리.

[프로젝트 회고]

  • 잘한 점

    • 성공적인 핵심 기능 구현: 어려운 기술적 도전에도 불구하고 C++ 아키텍처, AI 상호작용 등 프로젝트의 핵심 목표를 성공적으로 구현함.
    • 깊이 있는 기술 탐구: 문서화되지 않은 복잡한 문제(로딩 위젯, 플레이어 인덱스)에 대해 포기하지 않고, 팀원들과 함께 원인을 분석하고 해결책을 모색하며 기술적으로 크게 성장함.
    • 체계적인 개발 문화: DevLog, 자동화 스크립트 등을 통해 생산성 높은 개발 문화를 구축하고, 이를 통해 높은 몰입도와 빠른 개발 속도를 유지함.

  • 개선할 사항

    • 시연 및 발표 환경의 중요성: 최종 발표 시연이 개발 환경(PIE)과 다른 실제 환경(Standalone PC)의 차이, 그리고 예측하지 못한 하드웨어 및 네트워크 이슈로 인해 준비한 모든 것을 보여주지 못함. "시연은 실제 환경에서, 여러 번의 리허설을 거쳐야 한다" 는 교훈을 얻음.
    • 복잡한 시스템에 대한 이해: World Partition과 Seamless Travel의 동시 사용과 같이 복잡하고 새로운 시스템을 도입할 때, 초기 단계에서 더 깊이 있는 R&D와 기술 검증의 필요성을 느낌.
    • 비동기 커뮤니케이션 보완: 팀원 간의 주 작업 시간대가 다를 경우, 칸반 보드나 정기적인 비동기 체크인 등 진행 상황 공유를 명확히 할 수 있는 추가적인 장치의 필요성을 느낌.
