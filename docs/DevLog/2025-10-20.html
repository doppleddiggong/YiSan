  • [UI] MegaPopup에 닫기 기능 추가 및 로직 개선 (5083339) — dopple @ 2025-10-19T23:23:46+09:00

    • UMegaPopup에 CloseButton을 추가하고, 클릭 시 UBroadcastManager를 통해 팝업 닫기 이벤트를 전송하도록 구현했습니다.

    • UMainWidget이 팝업 닫기 이벤트를 수신하여 ToggleMegaPopup 함수를 호출하도록 수정했습니다.

    • ToggleMegaPopup 함수의 로직을 개선하여, 팝업이 열려 있을 때와 닫혀 있을 때를 명확히 구분하여 처리하도록 변경했습니다.

    • SetVisibility로 팝업을 닫을 때 NativeDestruct가 호출되지 않는 문제를 해결하기 위해, UMegaPopup에 OnClose 함수를 추가하여 사운드 재생과 같은 리소스를 명시적으로 해제하도록 했습니다.

    • 이를 통해 UI 컴포넌트 간의 결합도를 낮추고, 팝업의 상태 관리 로직을 개선했습니다.

  • [UI] SmallPopup C++ 기능 구현 및 리팩토링 (f8b7215) — dopple @ 2025-10-19T18:08:22+09:00

    • 기존 SmallPopup 위젯을 C++ 기반의 USmallPopup으로 재작성하고

    Unreal Engine 명명 규칙에 맞게 클래스 이름을 변경했습니다. (SmallPopup -> USmallPopup, MegaPopup -> UMegaPopup)

    • UMainWidget에서 블루프린트 이벤트를 통해 팝업을 업데이트하던 로직을 C++ 함수 호출 방식으로 변경하여 종속성을 제거하고 성능을 개선했습니다.

    • 팝업의 가시성(visibility)을 관리하는 로직을 개선하고 관련 함수(IsMegaPopupVisible, IsSmallPopupVisible)를 추가했습니다.

    • 건물 근접 시 호출되는 OnNearBuilding 이벤트 로직을 C++로 이전하고 최적화했습니다.

    • 위젯 블루프린트(WBP_Main, WBP_MegaPopup, WBP_SmallPopup)를 C++ 클래스 변경사항에 맞게 업데이트했습니다.
