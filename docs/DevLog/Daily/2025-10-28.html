    기존 토스트 메시지 시스템을 다음과 같이 개선했습니다.

    • 멀티캐스트 RPC로 전환: GameState에서 각 플레이어 컨트롤러에 개별적으로 RPC를 호출하는 대신, 멀티캐스트 RPC를 사용하여 모든 클라이언트에 한 번에 메시지를 전송하도록 변경했습니다. 이를 통해 네트워크 효율성을 높였습니다.

    • 서버 RPC 책임 변경: 토스트 메시지 요청의 시작점을 PlayerControl로 변경하여, 클라이언트의 요청을 받아 GameState의 멀티캐스트 RPC를 호출하도록 수정했습니다.

    • 쿨다운 기능 추가: 특정 시간 내에 토스트 메시지가 중복으로 표시되는 것을 방지하기 위해 PlayerControl에 쿨다운 기능을 추가했습니다.

    • UI 메시지 변경: 시작 버튼 클릭 시 나타나는 메시지를 "호스트가 시작 버튼을 눌렀습니다"에서 "모든 플레이어가 준비되면 시작됩니다"로 변경하여 명확성을 높였습니다.
