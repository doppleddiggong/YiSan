일일 개발 로그 2025-10-26 (KST 09:00 경계)

요약

  • 다산 NPC 투어에 음성 설명과 상태 시스템을 통합해 투어 진행 흐름과 방송 매니저 연계를 확장했습니다. / Integrated narrated tour states for the Dasan NPC, wiring them into the broadcast manager.
  • 음성 커맨드와 TTS 재생 파이프라인을 전면 재구성해 리샘플링, 소환 명령, 대화 위젯 서비스화를 완성했습니다. / Rebuilt the voice command and TTS playback stack with resampling, summon intent, and global dialog services.
  • 네트워크/로딩 UI와 메가 팝업, 상태 위젯 등 핵심 UI를 대규모로 정비하여 사용자 경험을 개선했습니다. / Overhauled loading, mega popup, and state widgets for a smoother front-end experience.
  • 건물 안내용 오디오·텍스처 리소스를 대량 반입하고 BGM 믹스와 위치를 조정했습니다. / Imported extensive building tour audio/texture assets and tuned ambient BGM placement.

하이라이트

  • NPC 투어 음성 통합: 투어/설명 상태 시스템과 GameState 확장으로 NPC 투어 동기화를 강화했습니다. (fdea60fe)
  • 음성 시스템 리샘플링: VoiceConversation/FunctionLibrary 개선으로 오디오 품질과 처리 경로를 정비했습니다. (d17e6b1d)
  • 다산 NPC 질의응답 UI: 상태 표시, 채팅 연동, 투어 시스템을 결합한 UI를 구축했습니다. (84284973)
  • 로딩 UX 개선: 네트워크 로딩 서브시스템과 글로벌 로딩 서클을 도입해 일관된 로딩 경험을 제공했습니다. (842b4105, 56814851, a956ac78)
  • 음성 명령 '소환' 추가: 신규 음성 커맨드와 리소스 세트를 통해 NPC 호출을 음성으로 처리합니다. (bd8beb49)
