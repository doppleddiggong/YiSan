주간 개발 요약 (2025-10-20 ~ 2025-10-26)

주간 개발 요약 (2025-10-20 ~ 2025-10-26)

주간 개요 / Weekly Overview

  • UI와 음성 시스템 대수선: 메가/스몰 팝업의 C++ 전환, 로딩·다이얼로그 UX 정비, 음성 파이프라인 리샘플링 등 전면적인 프론트엔드 안정화가 진행되었습니다.
  • 멀티플레이 인프라 강화: 로비 네트워크, 채팅 시스템, 전환 레벨 등 세션 기반 플레이의 기반을 마련했으며, 호스트-클라이언트 동기화 보강이 병행됐습니다.
  • NPC 투어 경험 확장: 다산 NPC 투어와 음성 내레이션이 BroadcastManager와 연동되며, 관광 콘텐츠 완성도를 한 단계 끌어올렸습니다.

핵심 성과 / Key Achievements

  1. 메가/스몰 팝업 C++ 리팩토링과 UI 상태 개선 — UI 이벤트를 C++로 이전해 의존성을 줄이고, 팝업 상태 관리와 사운드 해제 로직을 체계화했습니다.【F:Documents/DevLog/2025-10-20.md†L16-L61】
  2. 모듈형 채팅 시스템 통합 — LatteLibrary에 있던 채팅 모듈을 YiSan 프로젝트 전용으로 이관하고, FChatMessage 구조체 및 ChatUI 분리로 데이터 표현력을 높였습니다.【F:Documents/DevLog/2025-10-22.md†L5-L36】【F:Documents/DevLog/2025-10-23.md†L5-L36】
  3. 로비·로딩 파이프라인 안정화 — 로비 생성/연결 기능과 전환 레벨, GameInstance Subsystem 기반 비동기 로딩, 글로벌 로딩 서클이 도입되어 세션 전환 UX가 개선되었습니다.【F:Documents/DevLog/2025-10-21.md†L5-L30】【F:Documents/DevLog/2025-10-24.md†L5-L34】【F:Documents/DevLog/2025-10-26.md†L5-L44】
  4. 음성·TTS 스택 재구성 — 리샘플링, 소환 명령, LocalPlayerSubsystem화를 통해 음성 명령과 투어 내레이션을 서비스 레벨로 확장했습니다.【F:Documents/DevLog/2025-10-26.md†L5-L69】
  5. 문서·데이터 자산 정비 — 헤더 도큐먼트 한글화와 DevLog 백필, 투어용 오디오/텍스처 리소스 대량 반입으로 레퍼런스 품질과 테스트 데이터가 강화되었습니다.【F:Documents/DevLog/2025-10-20.md†L33-L61】【F:Documents/DevLog/2025-10-26.md†L69-L83】

역할별 리뷰 / Role-based Review

클라이언트팀장 관점

  • 평가: UI/네트워크 동시 정비로 클라이언트 체감 품질이 상승했으며, 음성 시스템이 서비스 레벨로 정착하는 단계에 도달했습니다.
  • 개선 제안: 신규 자산과 서브시스템 추가에 따른 성능, 메모리 가드라인을 정량화하고 코드/블루프린트 의존성 지도를 최신화해야 합니다.

PM 관점

  • 평가: 멀티플레이 로비와 NPC 투어 등 핵심 마일스톤이 주 단위로 전진했고, 롤백을 통한 리스크 관리가 적절하게 수행되었습니다.
  • 개선 제안: 자동화 DevLog 실패와 같은 프로세스 리스크에 대해 소유자와 일정 영향을 명확히 공유하는 커뮤니케이션 플랜이 요구됩니다.

PD 관점

  • 평가: 다산 NPC 투어와 음성 내레이션 확장으로 콘텐츠 가이드 경험이 눈에 띄게 향상되었습니다.
  • 개선 제안: 증가한 오디오/텍스처 자산에 맞춰 연출·사운드 품질 가이드와 QA 체크리스트를 업데이트해야 합니다.

리드 클라이언트 관점

  • 평가: C++ 전환과 Subsystem화가 일관되게 진행되어 코드 기반이 안정화되고 있으며, 네트워크/음성 시스템 간 연동성이 향상되었습니다.
  • 개선 제안: 시스템 간 인터페이스 계약(Events, Delegates)을 명문화하여 추후 확장 시 회귀를 방지하고, 복잡해진 로딩 루틴에 대한 성능 지표를 수집해야 합니다.
