2025-10-23

일일 개발 로그 2025-10-23 (KST 09:00 경계)

요약

  • 채팅 시스템을 대폭 리팩토링하여 데이터 구조와 UI 로직을 개선했습니다.
  • CoffeeToolbar 플러그인의 설정 관리와 관련된 주요 문제를 해결했습니다.
  • 맵 간의 원활한 이동을 위해 전환 레벨을 구현했습니다.
  • 채팅 입력 및 플레이어 컨트롤 포커스와 관련된 여러 버그를 수정했습니다.

하이라이트

  • 채팅 시스템 데이터 리팩토링: 채팅 시스템을 FString 대신 전용 FChatMessage 구조체를 사용하도록 개선하여 발신자 유형 및 모양과 같은 더 자세한 메시지 데이터를 허용했습니다. (48a493de)
  • CoffeeToolbar 설정 수정: 툴바 설정이 프로젝트의 .ini 파일에서 올바르게 로드되지 않는 중요한 문제를 해결했습니다. 이는 설정을 사용자별에서 프로젝트별로 이동하는 주요 변경 사항이었습니다. (f7d4a93a)
  • 전환 레벨: 시작 맵과 메인 맵 사이의 로딩 경험을 개선하기 위해 심리스 트래블의 중간 매개체 역할을 하는 새로운 Trans_Level을 만들었습니다. (721f2bd5)
  • 채팅 입력 수정: 채팅 입력이 올바르게 처리되지 않고 플레이어 입력 포커스가 "GameAndUI"와 "UIOnly" 모드 사이에서 제대로 전환되지 않는 버그를 수정했습니다. (d06ac2e2)
