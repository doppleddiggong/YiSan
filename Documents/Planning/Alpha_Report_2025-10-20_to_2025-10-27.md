# Alpha 단계 개발 보고서

**기간:** 2025년 10월 20일 ~ 2025년 10월 27일

## 1. 주요 변경 사항

이번 보고 기간 동안 프로젝트의 핵심 기능인 **네트워크, NPC 상호작용, 음성 시스템, UI/UX** 전반에 걸쳐 큰 진전이 있었습니다. 주요 내용은 다음과 같습니다.

- **네트워크 및 멀티플레이어:** 로비 시스템의 기본 골격을 완성하고, 플레이어 간 원활한 이동을 위한 심리스 트래블 기능을 구현했습니다. 또한 모듈형 채팅 시스템을 도입하여 향후 확장성을 확보했습니다.
- **NPC 및 상호작용:** 핵심 NPC '다산'의 가이드 투어 및 질의응답 기능 개발에 착수했습니다. GameState를 중심으로 상태를 통합하여 안정적인 상호작용 기반을 마련했습니다.
- **음성 시스템:** 음성 명령('소환'), TTS 출력, 오디오 리샘플링 등 음성 인식부터 재생까지 이어지는 전체 파이프라인을 재구성하여 성능과 품질을 개선했습니다.
- **UI/UX:** 주요 UI(팝업, 로딩 화면, 채팅)를 C++ 코드로 리팩토링하여 성능을 최적화하고, 일관된 사용자 경험을 제공하기 위해 전역 로딩 및 다이얼로그 시스템을 도입했습니다.
- **코어 시스템:** 비동기 로딩 로직을 Game Instance Subsystem으로 이전하고, 플러그인 설정 오류를 해결하는 등 코드 구조를 개선하여 안정성을 높였습니다.

## 2. 세부 변경 사항

### UI/UX
- **팝업 시스템 리팩토링:** 기존 블루프린트 기반의 Mega/Small 팝업을 C++ 클래스(UMegaPopup, USmallPopup)로 재작성하여 성능을 개선하고, 닫기 기능 및 데이터 연동 로직을 보강했습니다.
- **채팅 시스템 개선:** 채팅 시스템을 별도 모듈로 구현하고, 메시지 데이터를 구조체(FChatMessage)로 관리하도록 변경하여 시스템 확장성을 높였습니다.
- **로딩 UI 통일:** 여러 상황에서 일관된 로딩 경험을 제공하기 위해 전역 로딩 서클(Global Loading Circle)과 관리 시스템을 도입했습니다.
- **NPC 상호작용 UI:** '다산' NPC의 상태를 표시하는 위젯과 질의응답(Q&A) UI의 기본 구조를 구현했습니다.

### 네트워크
- **로비 시스템:** 세션 생성(Host), 참여(Join), 연결 끊기 등 멀티플레이어 로비의 핵심 기능을 구현했습니다.
- **심리스 트래블:** `ServerTravel`을 활용하여 맵과 맵 사이를 끊김 없이 이동할 수 있도록 전환 레벨(Transition Level)을 구현했습니다.
- **동기화 문제 해결:** 호스트 플레이어가 다른 클라이언트의 위치를 덮어쓰던 문제를 해결하여 위치 동기화 정확도를 높였습니다.

### NPC (다산)
- **상태 머신 통합:** 투어, 설명, 유휴 등 NPC의 여러 상태를 GameState 중심으로 통합하여 관리의 일관성을 확보했습니다.
- **음성 투어 기능:** NPC가 특정 지점에서 음성 해설을 제공하는 투어 기능의 기반을 마련하고, 방송 매니저(BroadcastManager)와 연동했습니다.
- **음성 명령 연동:** '소환' 음성 명령에 NPC가 반응하도록 관련 로직을 추가했습니다.

### 음성 시스템
- **파이프라인 재구성:** 음성 처리 파이프라인을 16kHz 리샘플링 기반으로 재편하여 TTS 및 음성 인식 품질을 향상했습니다.
- **전역 다이얼로그 시스템:** TTS 재생 로직을 LocalPlayerSubsystem 기반의 전역 서비스로 구현하여 어디서든 일관된 다이얼로그를 호출할 수 있도록 개선했습니다.
- **'소환' 명령 추가:** '다산' NPC를 호출하는 '소환' 음성 명령을 추가하고 관련 오디오 리소스를 통합했습니다.

## 3. 해결된 주요 문제
- `MegaPopup` 위젯이 닫힐 때 사운드 등 리소스가 정상적으로 해제되지 않던 문제를 해결했습니다. (2025-10-20)
- `CoffeeToolbar` 플러그인 설정이 사용자(`.ini`)가 아닌 프로젝트 레벨에서 로드되지 않던 문제를 수정했습니다. (2025-10-23)
- 채팅 입력 시 게임과 UI 간의 포커스가 올바르게 전환되지 않던 오류를 해결했습니다. (2025-10-23)
- 멀티플레이 환경에서 호스트가 다른 클라이언트의 위치 정보를 덮어쓰던 동기화 문제를 수정했습니다. (2025-10-25)
